    shared_creation_lock(key) ¶

    Per-key lock held by DaskSession.open() across acquire-or-create.

    Without it, two concurrent first opens of the same key both miss try_acquire_shared_session and both create a cluster; the second register_shared_session then overwrites the first entry, leaking the first cluster and corrupting the ref count.

    register_shared_session(key, *, client, cluster, holder=None) ¶

    Register client under key with one holder (holder, when given).

    detach_shared_session(key) ¶

    Remove and return the entry for key (ref count and holders included) without closing it.

    Used by :meth:DaskSession.rebind, which registers the replacement under the same key, then carries the holders over with :meth:carry_over_shared_holders and closes the old client itself.

    restore_shared_session(key, entry) ¶

    Put back an entry taken with :meth:detach_shared_session after a failed rebind.

    carry_over_shared_holders(key, previous) ¶

    Give the entry now registered under key the holder count and holders of previous.

    Returns the live holders so the caller can point each at the new client.

    DaskSession ¶

    Bases: SessionRebindMixin, ManagedResource

    A Dask distributed session backed by a :class:ManagedResource lifecycle.

    Accepts an existing client, connects to a scheduler address, or creates a cluster. Supports shared (multi-holder) and managed (single-holder) sessions.

    verify_connectivity (default on) pings the scheduler, waits for a worker and runs one task within :class:ConnectivityCheck.timeout; failure raises :class:DaskSessionUnavailable. telemetry becomes the process provider on open (:mod:boti_dask.telemetry). upload ships code to the workers on open and after a rebind (:mod:boti_dask.upload). watchdog keeps probing after open and calls :meth:rebind after repeated failures (:mod:boti_dask.watchdog); it applies to clients the session creates.

    namespace property ¶

    Prefix for this session's cluster primitives (:mod:boti_dask.primitives).

    The explicit shared_key when given; otherwise a digest of the derived pool key for a shared session, or of this object's identity for a managed one, so two sessions never share a primitive by accident.
